۷، ۲، ۹، ۱، ۵

می‌خوایم اون‌ها رو از کوچک به بزرگ مرتب کنیم.

یکی از روش‌های ساده، Bubble Sort است.

در این روش، عناصر مجاور با هم مقایسه می‌شن و اگر ترتیبشون اشتباه باشه، جابه‌جا می‌شن.

این فرایند چند بار تکرار می‌شه تا آرایه مرتب بشه.

آیا این بهترین روش است؟

برای یادگیری، Bubble Sort روش ساده‌ایه.

اما برای فهرست‌های بزرگ، معمولاً الگوریتمi‌های کارآمدتری وجود دارن.

برای نمونه، Merge Sort و Quick Sort در شرایط مناسب می‌تونن برای داده‌های بزرگ عملکرد بهتری داشته باشن.

با این حال، عملکرد واقعی به شرایط اجرا، نوع داده و پیاده‌سازی وابسته است.
